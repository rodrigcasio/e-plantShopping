# E-Plant Shopping (React)

This is a React e-commerce web application I built as part of my IBM Full-Stack Developer certification course on Coursera. The project focuses on learning React components, modern web development, and building interactive e-commerce functionality.

## What does it do?

- **E-commerce Store**: A complete online plant shopping experience with product catalog and shopping cart.
- **Product Management**: Browse and view different types of plants with detailed information and pricing.
- **Shopping Cart**: Add items to cart, manage quantities, and proceed through checkout process.
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices.
- **Interactive UI**: Modern React components with smooth user interactions and animations.

## Why did I make this?

I built this project to get comfortable with React and modern web development while following the IBM Full-Stack Developer course curriculum. It helped me understand:
- How to build interactive e-commerce applications with React
- Component-based architecture and reusability
- State management for shopping cart functionality
- Responsive web design principles
- Modern UI/UX practices for web applications

## Technologies Used

- **React**: Frontend framework for building user interfaces
- **JavaScript**: Core programming language
- **CSS**: Styling and responsive design
- **HTML**: Structure and markup
- **Vite**: Build tool for fast development and optimized production builds

## How to Run

1. Make sure you have Node.js installed on your computer.
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm run dev
   ```
4. Open your browser and visit the local development URL (usually `http://localhost:5173`)
